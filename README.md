# TagMyAudio Website

Website and 24 PDF guides for TagMyAudio 1.8.6, in twelve languages. English is the default; choose another language in the header.

Open `index.html` locally or serve this directory with a static web server. No Node.js runtime or build step is required.

Downloads link to the TagMyAudio GitHub release. Binaries are hosted in Releases rather than in this repository. SHA-256 values are shown beside the download buttons.

Languages: English, French, Spanish, Italian, Portuguese, Russian, Japanese, Hindi, Chinese, Korean, Indonesian and Turkish.

The supplied design, screenshots, translations and guides have been retained. The PayPal link remains unconfigured pending the official donation URL.

[Application source and releases](https://github.com/Lufscale/TagMyAudio)

No domain or hosting configuration is changed by this repository import.
